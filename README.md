## What the image shows

A newspaper front page for Wednesday 18 November 2026. The masthead reads
"THE WORLD — 18 NOVEMBER 2026" over an illustration of the day's biggest
story: the Quad summit in Manila, with the leaders of the United States,
Japan, India and Australia around the table beneath the Manila Bay skyline
at dusk. Below it, the day's other front-page headlines:

- **Trump in Manila for Quad talks** — US President Donald Trump arrived in
  Manila for Quad talks with regional allies, ahead of a visit to China.
- **Ukraine strikes Crimea bridge** — Ukraine hit the bridge linking Russia
  to Crimea for a second consecutive day, as Russia pounded bridges in Kyiv.
- **Iran drones hit US radar in Bahrain** — Iran attacked a US military
  radar system in Bahrain with drones, sharply raising Gulf tensions.

The image is a single 1024×1024 PNG, generated as an editorial illustration
and checked for legibility before submission.

## Run it

```bash
python3 main.py
```

This copies the bundled `entry.png` byte-for-byte to
`$MAKEFUN_OUTPUT_DIR` (or `./output` if unset) as `entry.png`.
Python 3.13, standard library only — no network, no randomness, fully
deterministic: two runs produce byte-identical output.
